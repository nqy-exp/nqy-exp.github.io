Installation

Please ensure that Python 3.8 or higher is installed on your system.

pip install flask pandas openpyxl watchdog Pillow python-dotenv

Naming Convention

This is the most critical part of using NIU. Please strictly adhere to the following format:

[Prefix]-[Sequence].[Extension] (e.g., T001-01.jpg)
